# Security policy

## Reporting a vulnerability

Report security findings privately through this repository's GitHub private vulnerability reporting channel: the **Report a vulnerability** button on the [Security](https://github.com/Boris13-tech/iam-azure-pme/security) tab.

Do not open a public issue, pull request or comment for a vulnerability that is not fixed. This repository is public.

## Reviewers

Independent reviewers use the same channel for any finding that could help an attacker. Findings without that risk can go directly on the pull request under review.
